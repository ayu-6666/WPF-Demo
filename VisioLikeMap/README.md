# VisioLikeWpf48 Enhanced

Visio 风格流程图编辑器，WPF + C# + .NET Framework 4.8，无第三方流程图控件依赖。

## 环境
- Windows 10/11
- Visual Studio 2019 / 2022
- .NET Framework 4.8 Developer Pack

## 打开运行
使用 Visual Studio 打开 `VisioLikeWpf48.csproj`，目标框架为 .NET Framework 4.8，生成并运行。

## 本次增强
1. 自定义标题栏：自定义最小化、最大化/还原、关闭按钮；WindowChrome 保留窗口边缘调整大小和标题栏拖动。
2. 工具栏美化：圆角按钮、悬停/按下状态、ToggleButton 当前工具选中高亮。
3. 连接线右键菜单：反转箭头、实线/虚线切换、单向/双向切换、编辑连接 Tag、删除连接。
4. 连接线选中：绿色高亮；显示绿色端点控制柄；拖动端点后自动吸附到最近节点边缘并更新节点关联。
5. 节点选中：绿色边框；节点 Tag 外框同步绿色高亮。
6. 流程方向：左到右、上到下两种自动排列方向。
7. 底部深色状态栏和缩放比例显示。
8. XML 保存/打开、PNG 高清导出（1x/2x/4x/8x）。
9. 保留 Ctrl+点击多选、空白处框选、滚轮缩放、空格拖动画布、Ctrl+Z/Y。

## 操作
- 添加图形：点击图形工具按钮。
- 连线：点击“连接箭头”，再点击起点和终点。
- 编辑连接：右键连接线或连接 Tag。
- 改变连接点：选中连接线，拖动两端绿色圆形控制柄到目标节点。
- 多选：Ctrl+点击节点；或在空白画布拖框。
- 平移：按住空格拖动画布。
- 缩放：鼠标滚轮。
- 方向：点击“左 → 右”或“上 ↓ 下”。此操作会按当前节点集合重新排列。
- 撤销/重做：Ctrl+Z / Ctrl+Y。

## 注意
本项目源码已生成，但当前执行环境不是 Windows WPF 编译环境，未在此处运行 Visual Studio 实际编译。请在 Windows + VS2019/VS2022 + .NET Framework 4.8 Developer Pack 环境生成验证。

## 连接锚点拖拽增强
- 选中连接线后，绿色圆形端点控制柄可直接拖动。
- 拖动过程中连线端点跟随鼠标实时预览。
- 鼠标靠近任意目标节点的上、右、下、左四个锚点（24 世界单位吸附半径）时，显示绿色吸附预览圈。
- 松开鼠标后，连接端点绑定到最近的那个具体锚点，不再按整体布局方向推断锚点。
- 若松开时未进入任何锚点吸附范围，连接关系保持不变。
