# WxChatApp 项目开发文档

> 仿微信桌面聊天应用（WPF + SignalR），含独立服务端。本文档面向后续开发者，介绍架构、模块职责、通信协议、数据模型、本次新增功能实现细节与扩展指南。

---

## 1. 项目概览

| 项目 | 目标框架 | 说明 |
|------|---------|------|
| `WxChatClientApp/WxChatApp.csproj` | `net8.0-windows` | WPF 客户端（MVVM，CommunityToolkit.Mvvm） |
| `WxChatServer/WxChatServer.csproj` | `net8.0` | ASP.NET Core 服务端（Minimal API + SignalR + SQLite） |

> 模块为多工程结构，模块根目录不再有 `.csproj` / `.sln`；构建与打包见 [部署文档.md](部署文档.md) 与仓库根 `build_all.bat`。

功能范围：登录/注册、单聊、群聊、朋友圈、通讯录、设置、语音消息、文件发送、表情包、图片右键菜单（另存/下载）。

**默认服务端地址**：`http://127.0.0.1:5210`（客户端可用环境变量 `WXCHAT_SERVER` 覆盖，见 [AppConfig.cs](../WxChatClientApp/Services/AppConfig.cs)）。

## 3. 通信协议

### 3.1 REST API（前缀 `/api`，鉴权用 Header `Authorization: Bearer <token>`）

| 方法 | 路由 | 说明 |
|------|------|------|
| POST | `/api/auth/register` | 注册（account/password/nickname） |
| POST | `/api/auth/login` | 登录，返回 token + 用户信息 |
| POST | `/api/auth/logout` | 注销 token |
| GET / PUT | `/api/me` | 获取/修改个人资料 |
| GET | `/api/users/search?q=` | 按 WxId/昵称搜索用户 |
| GET | `/api/contacts` | 好友列表（含在线状态） |
| POST | `/api/friends` | 添加好友 |
| GET | `/api/conversations` | 会话列表（含未读数、最后一条摘要 Preview） |
| GET | `/api/messages?type=&id=&limit=&after=` | 拉取历史消息（after 为增量拉取） |
| POST | `/api/groups` | 建群 |
| GET | `/api/groups/{id}` | 群详情 |
| POST / DELETE | `/api/groups/{id}/members...` | 群成员增删 |
| GET | `/api/moments` | 朋友圈列表 |
| POST | `/api/moments` | 发朋友圈（文本 + 图片） |
| POST | `/api/moments/{id}/like` / `/comments` | 点赞/评论 |
| POST | `/api/upload` | **通用文件上传**（≤20MB；拦截 .exe/.bat/.cmd/.com/.scr/.msi/.js/.vbs/.ps1/.sh） |

健康检查：`GET /api/health`、`GET /`。

### 3.2 SignalR（`/hub`）

客户端调用：

| 方法 | 参数 | 说明 |
|------|------|------|
| `SendMessage` | convType, targetId, type, content, imageUrl, atUserIds | 发消息。type 白名单：`text` / `image` / `voice` / `file`（见 ChatHub.cs） |
| `MarkRead` | convType, convId | 标记会话已读，并给对方推回执 |

服务端推送：

| 事件 | 载荷 | 说明 |
|------|------|------|
| `message` | MessageDto | 新消息（含自己多端同步） |
| `conversationUpdated` | - | 会话列表变化 |
| `readReceipt` | convType, convId, readerId | 对方已读 |
| `presence` | userId, online | 上下线（连接级，内存登记） |

### 3.3 消息类型约定（重要）

消息体只占用 `type` / `content` / `imageUrl` 三列，各类型约定：

| type | content | imageUrl | 渲染 |
|------|---------|----------|------|
| `text` | 文本本体 | - | 文本气泡 |
| `image` | - | 图片 URL | 图片气泡（右键菜单：另存为图片/下载/打开） |
| `voice` | 秒数字符串（如 `"3"`） | 语音 WAV URL | 语音条（点击播放，播放中图标切换） |
| `file` | `"文件名|字节数"`（如 `"报告.pdf|20480"`） | 文件 URL | 文件卡片（点击弹出另存） |

会话列表摘要由服务端 `Db.Preview()` 生成：`[图片]`、`[语音]`、`[文件] 文件名`。

## 4. 数据库（SQLite）

库文件：`WxChatServer/bin/Debug/net8.0/App_Data/wxchat.db`（WAL 模式，随服务端自动建表）。

| 表 | 关键列 | 说明 |
|----|--------|------|
| `users` | id, account, pwd_salt, pwd_hash, nickname, signature, wxid, region, created_at | 密码 PBKDF2 存储 |
| `sessions` | token, user_id, created_at | 登录会话 |
| `friends` | owner_id, friend_id | 双向好友 |
| `groups` / `group_members` | id, name, owner_id / group_id, user_id | 群与成员 |
| `messages` | id, conv_type, conv_id, sender_id, **type**, **content**, **image_url**, at_users, created_at | 单聊 conv_id 为 `DirectConversationId(两人有序拼接)`，群聊 conv_id 为群 id |
| `message_reads` | message_id, user_id, read_at | 已读回执 |
| `moments` / `moment_images` / `moment_likes` / `moment_comments` | ... | 朋友圈 |

上传的媒体文件落盘在 `App_Data/uploads/`，由服务端静态文件中间件对外提供（URL 形如 `/uploads/<id>.<ext>`）。

## 5. 本次新增功能实现说明

### 5.1 图片右键菜单（另存为图片 / 下载 / 打开）

- 位置：`Views/ChatPaneView.xaml` 图片气泡 `Border.ContextMenu`（对方气泡与我的气泡两处）。
- 事件：`ChatPaneView.xaml.cs` 的 `SaveImageAs_Click`（SaveFileDialog → ApiClient.DownloadFileAsync）、`DownloadImage_Click`（免对话框直接存 `Downloads\wxchat_yyyyMMdd_HHmmss.ext`）、`OpenImage_Click`（Process.Start 打开本地缓存）。
- 关键辅助：`MenuData<T>` 从菜单项 DataContext 反查消息 VM（ContextMenu 不在可视树，`MenuItem.PlacementTarget` 为 null，需经 `ItemsControlFromItemContainer` 兜底）；`UniquePath` 处理重名；`MediaExtension` 根据 Content-Type/URL 推断扩展名。
- 图片本地缓存：`ImageUrlConverter` 下载到 `%LOCALAPPDATA%\WxChatApp\cache\` 后返回 BitmapImage。

### 5.2 表情包（双 Tab 面板 + 自定义导入）

- 面板：`ChatPaneView.xaml` 表情面板改为双 Tab（表情 / 表情包），绿色下划线指示；表情包页右上角 `+` 导入图片。
- 存储：`Services/StickerStore.cs`
  - 内置 12 个表情 `builtin\s1..s12.png`：首次运行程序化渲染生成（无需随包带图片资源）；
  - 自定义表情复制为 `user_*.jpg/png`；
  - 目录 `%LOCALAPPDATA%\WxChatApp\stickers\`，`LoadAll/AddFromFile/Delete` 全部本地持久化。
- 发送：表情包复用 `image` 消息管道（`ChatPaneViewModel.SendSticker` → 上传 → SendMessage type=image）。
- 添加/删除入口：`AddStickerCommand`（OpenFileDialog）、`StickerDelete_Click`（右键删除自定义表情）。

### 5.3 语音消息（录音 / 播放）

- 录音：`Services/VoiceService.cs`，NAudio `WaveInEvent`（16kHz、16bit、单声道 WAV）。
- 交互：点击工具栏麦克风进入语音模式（`VoiceMode`），输入框替换为蓝色「按住 说话」按钮；松开上传（`FinishVoiceRecordingAsync`），移动出按钮区域取消；<1s 提示"说话时间太短"。
- 消息：type=`voice`，content=秒数；气泡宽度随时长增长（`VoiceMinWidth`），播放中图标 `E768↔E769`（`VoicePlayGlyphConverter`）。
- 播放：`WaveOutEvent` + `AudioFileReader`；接收端首次点击从服务端下载缓存到 `%TEMP%\WxChatVoice\msg_<消息Id>.wav`，再次点击直接播放/停止。
- 播放状态回调跨线程，经 `Dispatcher` 回 UI（`ChatPaneViewModel.OnVoicePlayStateChanged`）。
- 退出登录（`SignOutAsync`）时停止录音/播放，防止后台占用麦克风。

### 5.4 文件发送

- 流程：`ChatPaneViewModel.SendFile` → OpenFileDialog → `ApiClient.UploadFileAsync`（POST /api/upload）→ SendMessage type=`file`，content=`文件名|字节数`，imageUrl=下载 URL。
- 渲染：文件卡片（E8A5 文档图标 + 文件名 + 格式化大小），整卡可点击。
- 接收：`FileBubble_Click` → SaveFileDialog → `DownloadFileAsync` 流式下载 → 内容与源文件逐字节一致（已实测）。
- 服务端安全：20MB 上限；扩展名黑名单拦截可执行脚本类文件。

### 5.5 服务端配套改动

- `Hubs/ChatHub.cs`：`SendMessage` 类型白名单放宽为 `text|image|voice|file`；`voice`/`file` 必须携带 imageUrl（媒体附件），否则拒绝。
- `Program.cs`：`/api/upload` 通用化（原仅图片）。
- `Data/Db.cs`：`Preview()` 支持 `[语音]`、`[文件] 名` 摘要。

## 7. 扩展指南

- **新增消息类型**：① 服务端 `ChatHub.SendMessage` 白名单加 type；② 约定 content/imageUrl 编码；③ `ChatMessageVm` 加 `IsXxx` + 展示属性；④ `ChatPaneView.xaml` 两处气泡 Grid 各加一个 Visibility 分支；⑤ 如需摘要，改 `Db.Preview()`。
- **新增 REST 接口**：`Program.cs` 用 Minimal API 直接追加，DTO 加到 `Models/Contracts.cs`，客户端在 `ApiClient.cs` 封装。
- **数据库迁移**：`Db.Init()` 的 `CREATE TABLE IF NOT EXISTS` 幂等；改表需手写 `ALTER TABLE`（建议加版本判断）。
- **表情包资源**：替换/增删内置表情只需调整 `StickerStore` 生成清单；自定义表情完全由用户目录驱动。
- **语音格式**：当前 WAV（16k/16bit/mono）。换 Opus/AAC 需同步改 `VoiceService`（录制编码）、`MediaExtension`、播放端解码（NAudio 需对应编解码器）。

### 8.4 朋友圈九宫格布局 + ViewerWindow 弹框

**九宫格自适应**：`Converters.cs` 新增两个 Converter：
- `ImageGridColumnsConverter`：1→1（大图），2~3→count，4→2，5+→3

**ViewerWindow 图片/视频弹框**（`Views/ViewerWindow.xaml + .cs`，全功能实现）：

## 12. 中英文界面切换（本轮）

### 12.1 方案与取舍

- 采用 `ResourceDictionary`（`sys:String` 条目）+ `{DynamicResource}`，而非 resx：字典可在运行时整体替换并立即刷新所有绑定，无需重启或逐控件通知；代码侧统一走 `Loc.T(key)`。
- 资源位置：`WxChatApp/Resources/Strings.zh-CN.xaml`、`Strings.en-US.xaml`；两文件键集合必须一致。
- 切换机制：`Services/Localization.cs` 的 `Loc.Apply()` 从 `Application.Current.Resources.MergedDictionaries` 移除旧字典再追加新字典（WPF 从后往前查找），覆盖 `App.xaml` 内默认中文；同时设置 `CultureInfo`（`zh-CN` / `en-US`）。
- 切换入口：设置页「界面语言」下拉（`LanguageCombo`，`Settings.Language` / `Settings.LanguageZh` / `Settings.LanguageEn`）。切换即 `Loc.SetLanguage(..., persist:true)`，语言立即持久化且不随「取消」回滚；其它设置仍保持原回滚语义。
- 持久化：`LocalSettings.Language`（默认 `zh-Hans`）写入 `%LocalAppData%\WxChatApp\settings.json`，启动时 `Loc.Initialize()` 读取。
- 派生文案刷新：`Loc.LanguageChanged` → `ShellViewModel.OnLanguageChanged()` 统一刷新会话列表、搜索项、聊天窗、朋友圈、联系人；各 VM 提供 `NotifyLanguageChanged()`，避免多点订阅泄漏。
- 日期/数字：`Helpers/TimeFormatter.cs` 按 `Loc.Culture` 输出（今天 `HH:mm`、昨天、`M月d日`/`MMM d`、`yyyy/M/d`/`M/d/yyyy`、`分钟前`/`min ago`）；`UnreadText` 用 `Loc.Culture.ToString` 格式化数字。

## 14. 服务端单文件分发修复（2026-11-07）

### 14.1 问题与根因

- 现象：双击 `WxChatServer.exe`（或把该 exe 单独拷贝到别处双击）时，控制台一闪而过，服务未启动。
- 根因：`publish\server` 是**框架依赖多文件发布**，apphost `WxChatServer.exe` 启动时必须在同目录找到 `WxChatServer.dll`、`WxChatServer.deps.json`、`WxChatServer.runtimeconfig.json`。实测把 exe 单独复制到空目录后报：
  `The application to execute does not exist: '...\WxChatServer.dll'`，随后进程立即退出——双击时窗口随即关闭，看起来就是"双击无法运行"。
- 另外，框架依赖版要求目标机安装 **.NET 8 运行时**，换机部署也会失败。

### 14.2 修复方案

- 服务端改为**自包含单文件发布**：
  `dotnet publish WxChatServer.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=none -o publish\server`
- 产物：`publish\server\WxChatServer.exe`（约 93.8 MB），内置 .NET 8 运行时、ASP.NET Core 与 SQLite 原生库（`e_sqlite3` 首次运行自解压），**单个 exe 即可运行，无需安装运行时、无需同目录 dll**。
- `scripts\deploy-server.bat` 默认发布命令同步改为上述单文件参数，并在发布前清理旧的多文件产物（只保留 `App_Data` 数据库目录）。
- 数据目录仍为 `AppContext.BaseDirectory\App_Data`（即 exe 同目录），可用环境变量 `WXCHAT_DATA` 指向其它绝对路径。

### 14.3 验证（真实环境）

- 空目录只放一个 `publish\server\WxChatServer.exe`（无 dll/deps/runtimeconfig），`Start-Process` 以该目录为工作目录启动：
  - 进程存活，日志显示 `Content root path` 与 `数据目录` 均为该空目录；
  - `GET http://127.0.0.1:5210/api/health` → `{"ok":true,...}`（HTTP 200）。
- 对照组（旧多文件 exe 单独拷贝）：立即退出并输出 `The application to execute does not exist: ...WxChatServer.dll`，复现用户所述现象。
- 发布后 `publish\server` 仅含 `WxChatServer.exe` + 可选 `App_Data`（及 IIS 用的 `web.config`），无残留旧 dll。

### 14.4 已知限制

- 单文件体积约 94 MB；首次启动需自解压原生库，冷启动比多文件版略慢。
- Windows SmartScreen 可能对未签名 exe 提示"未知发布者"，选择"仍要运行"即可；生产环境建议代码签名。
