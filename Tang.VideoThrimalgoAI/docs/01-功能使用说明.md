# Tang.VideoThrimalgoAI 功能使用说明

面向最终用户。所有处理均在本机完成：图像用本地 OpenCV/ONNX 推理，视频只调用本机 ffmpeg/ffprobe，不访问网络。

## 1. 界面结构

程序启动后是一个自绘标题栏窗口（`WindowStyle=None` + WindowChrome，无系统边框）。

| 区域 | 位置 | 说明 |
|---|---|---|
| 标题栏 | 顶部，高 44px | 左侧显示程序名与副标题“图像 / 视频修复智能工作台”；右侧为最小化、最大化/还原、关闭按钮，可拖拽移动、双击最大化 |
| 页签 | 标题栏下方 | “图像修复 / 视频处理”两个页签，点击切换；页签文字随语言切换 |
| 左侧控制栏 | 图像页宽 340px，视频页宽 380px | 参数、素材、操作、输出、状态；内容较长时自带滚动条 |
| 右侧预览区 | 占满剩余宽度 | 图像页显示当前图与尺寸、最近打开列表；视频页显示首帧缩略图、媒体信息、输出路径与耗时 |

窗口默认 1500×920，最小 1000×680，居中启动。

## 2. 图像修复页

### 2.1 功能一览

| 功能 | 做什么 | 怎么用 | 会得到什么 |
|---|---|---|---|
| 打开图片 | 载入单张图并预览 | 点“打开图片”，选择文件 | 右侧预览 + 尺寸；文件进入“最近打开” |
| 画质增强 | 轻度纯算法修复（保边降噪 + 细节重建 + 温和色调） | 修复模式选“画质增强”，点“开始修复” | 输出目录下 `原名_processed.png` |
| 高清修复 | 完整修复；可选 ONNX 超分重建细节 | 修复模式选“高清修复”，选修复强度/2x/超分模型，点“开始修复” | 同上，分辨率可能提升 |
| 去马赛克 | 降噪 + 锐化 + 时域融合的近似处理（固定强度 8） | 修复模式选“去马赛克”，点“开始修复” | 块状观感减弱，但被抹除的信息不会真正恢复 |
| 去水印 | 用 delogo 覆盖图中固定区域（默认右下角 30%，最大 260×200） | 修复模式选“去水印”，点“开始修复” | 水印区域被邻域插值覆盖；图像页不支持手动框选 |
| 水平校正 | 自动估计倾角并旋转校正 | 修复模式选“水平校正”，点“开始修复” | 校正后的图；|角度|>30° 时视为无倾角，<0.05° 不旋转 |
| 输出目录 | 指定保存位置 | 点“输出目录”选择文件夹 | 后续单图/批量结果都写入该目录 |
| 批量修复 | 对整个文件夹做同一处理 | 点“批量修复”，选择输入文件夹 | 结果平铺输出；弹窗显示成功/失败数 |

图像预览的缩略图按 1200px 宽解码显示，不影响实际处理分辨率。

### 2.2 修复强度（三档）

| 档位 | 实际强度（代码内参数） | 适用 |
|---|---|---|
| 轻度 | 细节增益 0.35、边缘阈值 3.0/5.0、目标亮度 126 | 干净图、只想轻微提升 |
| 标准（默认） | 细节增益 0.70、边缘阈值 2.5/4.0、目标亮度 128 | 多数照片 |
| 强 | 细节增益 1.10、边缘阈值 2.0/3.5、目标亮度 130 | 低清、偏暗、细节糊 |

注意：**“修复强度”只对“高清修复”生效**；“画质增强”固定使用轻度档（单图与批量均如此），避免过度锐化。

### 2.3 2x 放大与超分模型

| 控件 | 默认 | 行为 |
|---|---|---|
| 2x 放大 | 未勾选 | 勾选后纯算法按 Lanczos 2x 放大再重建；源图超过 2000 万像素时跳过放大 |
| 超分模型 | 关闭 | 可选“Real-ESRGAN 4x”（本地 ONNX）。未勾选 2x 时输出 4x；勾选 2x 时用 4x 重建后降采样为 2x |
| 模型状态行 | — | 三态：“关闭（使用纯算法修复）” / “可用（输出 2x 或 4x，本地离线推理）” / “不可用：原因（将回退纯算法）” |

- 模型文件缺失、哈希不符、加载失败或输入超过 400 万像素时，自动回退纯算法，状态栏会标出“→ 纯算法回退”。
- CPU 推理很慢：实测 960×600 约 4–5 分钟、1280×800 约 8 分钟（2x）；批量开启超分时请预估耗时。
- 模型对失焦、严重模糊图无法“无中生有”恢复细节，收益有限；高调图可能轻微改变色调。
- 模型来源与许可见 `Models\NOTICE.txt`（BSD-3-Clause）。

### 2.4 参数调节

| 参数 | 范围 | 默认 | 作用 |
|---|---|---|---|
| 亮度 | -50 ~ +50 | 0 | 轻微提亮/压暗 |
| 对比度 | 0.5 ~ 2.0 | 1.00 | 温和对比调整 |
| 锐度 | 0.5 ~ 2.5 | 1.20 | 细节重建强度倍率 |

这三个参数参与“画质增强/高清修复”，对其余模式无效。

### 2.5 单图与批量输出

| 项 | 规则 |
|---|---|
| 单图输出 | `{输出目录}\{原文件名}_processed.png` |
| 批量输入 | 选择文件夹后递归扫描；扩展名 `.png/.jpg/.jpeg/.bmp/.tif/.tiff/.webp`；跳过文件名以 `_processed` 结尾的文件 |
| 批量输出 | 全部平铺到输出目录，命名同为 `{原文件名}_processed.png` |
| 输出格式 | 统一保存为 PNG（不保留原格式） |
| 默认输出目录 | 系统“图片”文件夹 |

批量结束弹窗显示“批量完成：成功 x / 失败 y / 共 z，耗时…”；失败明细最多列 8 项，超出显示“等共 N 项失败”。若超分模型不可用，会额外弹出“批量处理提示”，说明本批已回退纯算法。

### 2.6 图像页状态栏消息

| 消息 | 含义 |
|---|---|
| 就绪 / 已加载图像 | 空闲或载入成功 |
| 图片文件不存在 / 无法解码图片文件 | 路径失效或格式损坏 |
| 加载失败：{原因} | 读取异常 |
| 请先打开图片，再开始修复 | 未选图就点开始 |
| 正在处理：{模式}… | 处理中 |
| 高清修复完成（{强度}强度，{模式}，{W}x{H}，耗时 {s}s） | 成功；{模式}为“纯算法”或“ONNX Real-ESRGAN x4plus 4x→2x” |
| 处理完成（校正角度 {x}°，耗时 {s}s） | 水平校正成功 |
| 处理完成（耗时 {s}s） | 其余模式成功 |
| 处理失败：{原因} | 解码/写入失败 |
| 输出目录已设置：{路径} | 目录已选择 |
| 批量进度 {n}/{总}：{文件} | 批量进行中 |
| 所选文件夹中未找到图片（支持 …） | 目录为空或无匹配扩展名 |
| 批量完成：成功 x / 失败 y / 共 z，耗时… | 批量结束 |

### 2.7 图像页已知限制

- 纯算法只能增强已有信息，不能生成真实新细节；失焦图收益有限。
- 超分走 CPU，单张耗时以分钟计；>400 万像素不走模型。
- “去水印”在图像页只能覆盖默认右下区域，复杂水印效果有限。
- “水平校正”只处理 ±30° 内的小角度。
- 输出固定 PNG，不提供 JPEG/WebP 保存选项。

## 3. 视频处理页

### 3.1 处理引擎

| 控件 | 说明 |
|---|---|
| FFmpeg 路径 | 只读显示当前 `ffmpeg.exe` 位置 |
| 浏览 | 手动指定 ffmpeg.exe；同目录必须存在 `ffprobe.exe` |
| 重新检测 | 按顺序重新查找（见下） |
| 引擎状态 | 找到/未找到、版本信息 |

自动查找顺序：已保存配置（`%LocalAppData%\Tang.VideoThrimalgoAI\settings.json`）→ 本机默认目录 `D:\tang\software\ffmpeg\bin` → 系统 PATH → 常见安装位置（`C:\ffmpeg\bin`、`C:\ffmpeg`、`C:\Program Files\ffmpeg\bin`、scoop、chocolatey）。

### 3.2 视频素材与预览

- “打开视频”支持 `.mp4/.mov/.mkv/.avi/.webm/.m4v/.flv/.wmv/.ts/.m3u8`（拼接待选列表不含 m3u8）。
- 选片后抽取 0.1s 处首帧生成预览（临时缩略图写入 `%LocalAppData%\Tang.VideoThrimalgoAI\preview`，加载后自动清理上一张）。
- 显示源文件的分辨率、帧率、时长、音轨编码；“状态”显示读取与处理消息。
- “输出目录”默认系统“视频”文件夹（不存在时退到桌面）。

### 3.3 九项功能

| 功能 | 做什么 | 怎么用 / 参数 | 得到什么 | 已知限制 |
|---|---|---|---|---|
| 高清修复 | Lanczos 放大 + HQDN3D 降噪 + Unsharp 锐化 | 放大倍数 1x/1.5x/2x/3x/4x（默认 2x）；降噪 0–100（默认 40）；锐化 0–100（默认 40） | `原名_enhanced.mp4` | 纯滤镜方案，放大细节是插值结果，非 AI 重建 |
| 去码（马赛克弱化） | 降噪 + 锐化 + 时域融合的近似弱化 | 时域融合帧数 1–5（默认 3）；降噪/锐化固定 40 | `原名_demosaic.mp4` | 只能降低块状观感，不能恢复被抹除的内容 |
| 去水印 | delogo 逐帧插值覆盖 | 在右侧预览上拖拽框选（可多个，宽/高 <4px 丢弃）；未框选时默认右下 30% | `原名_delogo.mp4` | 固定区域覆盖，不重建被遮挡内容 |
| 多视频合成 | 并排或画中画 | 选“第二个视频”；布局“并排/画中画”；画中画可选位置（左上/右上/左下/右下，默认右下）与比例 15–60%（默认 32%） | `原名_composed.mp4`；时长取两段较短者，保留第一个视频的音轨 | 以第一个视频为基准统一分辨率/帧率 |
| 视频拼接 | 按列表顺序顺序拼接 | “添加视频”至少 2 段，列表可逐项移除；按列表顺序执行 | `原名_concat.mp4`（**静音**） | 自动归一化分辨率/帧率/像素格式；不保留音轨 |
| M3U8 转 MP4 | 本地 HLS 播放列表转封装 | 选择本地 `.m3u8`（支持相对路径 ts 分片） | `原名_m3u8.mp4` | 优先 `-c copy` 无损转封装，失败才重编码；远程密钥加密的分片离线无法解密 |
| 提取音轨 | 只导出音频，不重编码视频 | 格式 MP3 / AAC(M4A) / WAV(PCM)（默认 MP3）；码率 128/192/256/320k（默认 192） | `原名_audio.mp3/.m4a/.wav` | 源无音轨时明确失败且不产出文件 |
| 分段裁剪 | 按时间截取片段 | 起始/结束滑杆（上限=视频时长）；模式“快速（关键帧对齐，默认）/精确（重编码）” | `原名_trim.mp4` | 快速模式起点对齐到关键帧，时长可能有零点几秒偏差；精确模式严格按时间 |
| GIF 生成 | 视频转 GIF | 帧率 3–30（默认 12）、宽度 120–1280（默认 480）、抖动 Sierra 2-4A/Bayer/Floyd-Steinberg/无、无限循环（默认勾选） | `原名_anim.gif` | GIF 仅 256 色，量化必然有损 |

输出文件统一放在“输出目录”，命名为 `{源文件名}_{后缀}`；后缀分别为 enhanced / demosaic / delogo / composed / concat / m3u8 / audio / trim / anim。

### 3.4 开始与取消

- “开始处理”在参数不满足时自动置灰（如未选视频/未指定 ffmpeg/拼接不足 2 段）。
- 处理中可“取消”，状态显示“已取消”。
- 完成时状态显示“处理完成：输出路径 / 耗时”；失败显示“处理失败：{原因}”（ffmpeg 的错误会被带回）。

### 3.5 视频页状态栏消息

| 消息 | 含义 |
|---|---|
| 就绪 / 已加载视频 | 空闲或选片成功 |
| 正在读取媒体信息… / 读取失败：… | 探测阶段 |
| 该文件不包含可解码的视频画面。 | 文件损坏或纯音频 |
| 未检测到 ffmpeg.exe，请点击“浏览”指定本地路径。 | 引擎未配置 |
| 指定的 ffmpeg.exe 不存在。 / 同目录缺少 ffprobe.exe。 | 路径无效 |
| 输出目录已设置：{路径} | 已选输出目录 |
| 正在启动本地 FFmpeg… / 正在处理… | 执行中 |
| 处理完成：{路径}（{note}） | 成功 |
| 已取消 | 用户取消 |
| 处理失败：{原因} | 执行失败 |
| 尚未框选区域，默认使用右下角 30% 区域 / 已框选 {n} 个区域 | 去水印状态 |

### 3.6 中英文切换

- 按钮位于视频页左栏标题右侧，中文界面显示“EN”，英文界面显示“中文”。
- 切换后更新：视频页全部文本（引擎、素材、功能名、参数、提示、输出、状态、语言按钮）以及顶部页签文字。
- **图像修复页正文为中文，不随切换变化**（仅页签标题变化）。

## 4. 支持格式

| 类型 | 支持 |
|---|---|
| 图片输入 | `.png .jpg .jpeg .bmp .tif .tiff .webp`（另可选“所有文件”） |
| 图片输出 | 仅 `.png` |
| 视频输入 | `.mp4 .mov .mkv .avi .webm .m4v .flv .wmv .ts .m3u8` |

## 5. 常见操作示例

### 示例 A：修复一张老照片（纯算法）

1. “打开图片”选择照片 → 修复模式“高清修复” → 强度“标准” → 按需勾选“2x 放大” → “开始修复”。
2. 结果保存到输出目录的 `原名_processed.png`；状态栏显示耗时与最终尺寸。

### 示例 B：低清人像用 AI 超分

1. 修复模式“高清修复”，“2x 放大”勾选（需要 2x）或取消（需要 4x）。
2. “超分模型”选“Real-ESRGAN 4x”，确认状态行为“可用（输出 2x/4x，本地离线推理）”。
3. 点“开始修复”，等待数分钟；状态栏若出现“→ 纯算法回退”，说明模型不可用或图过大。

### 示例 C：整批照片统一修复

1. 先点“输出目录”选定保存位置（建议不要选源图目录）。
2. 点“批量修复”选择输入文件夹（会递归子目录）。
3. 等待进度条结束，查看成功/失败统计；失败原因会列出文件名。

### 示例 D：视频高清修复 + 截取片段

1. 视频页确认 FFmpeg 路径 → “打开视频”选源片。
2. 功能“高清修复”，放大 2x、降噪 40、锐化 40 → “开始处理”，得到 `_enhanced.mp4`。
3. 换功能“分段裁剪”，拖动起止滑杆，快速模式先预览结果；需要严格时长时改“精确（重编码）”。
4. 再换“提取音轨”导出 MP3，或“GIF 生成”做动图。

### 示例 E：两段视频并排对比

1. 功能“多视频合成” → “选择文件”指定第二个视频。
2. 布局“并排” → 开始处理；输出宽度为两段宽度之和，时长取较短者，保留第一个视频音轨。
