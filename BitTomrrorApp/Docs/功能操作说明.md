# BitTomrrorApp 功能操作说明

> 版本：1.1 ｜ 更新日期：2026-11-04

**极速资源下载器**是一款桌面下载工具，支持五种资源类型的真实下载：

| 类型 | 支持内容 | 断点续传 |
|---|---|---|
| BT | .torrent 文件、磁力链接（magnet:?xt=urn:btih:...）、tracker + DHT + PEX、做种 | 支持（fast-resume） |
| HTTP(S) | 直链下载、重定向跟随、1~N 连接分片 | 支持（.part 续传） |
| M3U8 | HLS 直播/点播流、码率选择、AES-128 加密、EXT-X-MAP (fMP4) | 支持（分片级） |
| Telegram | Bot API 文件下载（单文件 ≤20 MB） | 支持 |
| FTP/FTPS | 直链或主机+路径、被动模式、可选显式 TLS | 支持（REST 偏移） |

所有进度、速度与"已完成"状态均来自真实传输与分片/文件哈希校验。

---

## 1. 启动与主界面

双击 `BitTomrrorApp.exe` 启动。若已设置**启动密码**，会先弹出解锁窗口：输入密码点击"解锁"进入；点击窗口关闭按钮则退出应用。

主界面从上到下：

- **标题栏**：左侧"极速资源下载器"与类型徽标；右侧齿轮按钮 = **个人设置中心**，以及最小化/最大化/关闭。
- **输入栏**：粘贴资源链接或 `.torrent` 文件路径，点击"添加任务"快速创建；"高级添加"打开多 Tab 表单；"选择种子"从本地文件选择 .torrent。
- **任务列表**：每个任务一张卡片（类型徽章、文件名、进度条、已下载/总量、速度、剩余时间、状态、详情）。
- **底部状态栏**：实时 ↓上传/下载 速度、任务统计（总数/进行中/已完成）、FFmpeg 可用性（影响 M3U8 合并方式）、批量暂停/批量删除。

**支持直接粘贴的输入**：

| 输入 | 行为 |
|---|---|
| `magnet:?xt=urn:btih:...` | 创建 BT 任务，经 DHT/tracker 获取元数据 |
| 本地 `.torrent` 路径 | 创建 BT 任务 |
| `http(s)://...` 普通文件 | 创建 HTTP 直链任务 |
| `http(s)://...m3u8` / `.m3u8` 结尾 | 创建 M3U8 任务 |
| `ftp://host/path/file` | 已在设置中心保存 FTP 信息 → 用保存的凭据直接建任务；否则提示先配置 |
| `t.me/...` 等 Telegram 链接 | 提示到"高级添加"填写 file_id（Token 已自动填充） |

## 2. 五类任务的操作方法

### 2.1 BT（种子 / 磁力）

**快速添加**：粘贴磁力链接或 .torrent 路径 → 添加任务。
**高级添加（BT Tab）**可设置：

- 保存目录
- 下载 / 上传限速（B/s，0 = 不限）
- 做种比例上限、做种时长上限（分钟）——二者都为 0 时，下载校验完成后即标记完成，不做种

下载过程显示：种子数 · 连接数 · 节点数、真实上下行速度、进度；下载完成后自动进行**分片哈希校验**（详情显示"N 个分片哈希有效"），校验通过转入完成或做种。失败分片自动重下。

> 提示：磁力链接首次需要通过 DHT 获取元数据，公网不可达时会一直显示"正在获取元数据"；建议优先使用 .torrent 文件。

### 2.2 HTTP 直链

- 快速添加：粘贴直链即可。
- 高级添加（HTTP Tab）：保存目录、**连接数**（1=单连接，>1 启用多连接分片并发）。
- 暂停后继续：从已下载字节处发 `Range` 请求续传，不会重头下载。

### 2.3 M3U8 (HLS)

- 高级添加（M3U8 Tab）：保存目录、**码率选择**（填写目标带宽，如 246000；留空自动选）、ffmpeg 路径（可选）。
- 自动处理 AES-128 加密分片解密、EXT-X-MAP 初始化段；分片失败自动重试。
- 合并：优先使用 ffmpeg 转封装为 mp4（底部状态栏显示"FFmpeg 可用"），未配置时使用内置拼接。
- 转封装完成后可用任意播放器校验；产物元数据可用 ffprobe 验证。

### 2.4 Telegram

前置条件：一个 Bot Token（向 @BotFather 创建机器人获取）。

1. 进入**个人设置中心 → Telegram 认证**，粘贴 Token（保存时会调用 getMe 校验），可选填默认 chat_id。
2. 点"高级添加 → Telegram Tab"：Token 与 chat_id 已自动填充，只需填写 **file_id**（或 chat_id + message_id，程序会通过 getUpdates 在最近消息中定位）。
3. 添加任务后即开始下载到指定目录。

> 注意：Bot API 单文件上限 **20 MB**；超过上限的任务会被直接拒绝（TG_FILE_TOO_LARGE），不会浪费流量。要传大文件需 bot 先通过本地 Bot API Server 上报文件，当前版本不支持。

### 2.5 FTP / FTPS

**推荐：先在设置中心保存连接信息**（见第 3 节），之后两种方式均可：

- 主界面直接粘贴 `ftp://主机/路径/文件` → 自动用保存的账号密码建任务；
- 高级添加（FTP Tab）：主机、端口（默认 21）、用户名（留空 = anonymous）、密码、远程路径、是否使用显式 FTPS (TLS)、保存目录。

连接失败、密码错误会显示明确原因（如 FTP_AUTH_FAILED：FTP 认证失败）。

## 3. 个人设置中心（标题栏齿轮按钮）

设置中心分三个 Tab，点击底部"保存设置"生效（凭据立即加密落盘）。

### 3.1 FTP 服务器

| 字段 | 说明 |
|---|---|
| 主机 | 域名或 IP |
| 端口 | 默认 21 |
| 用户名 | 留空表示匿名 (anonymous) |
| 密码 | 仅保存在本机，经 Windows DPAPI 加密后写入配置文件 |
| 默认远程目录/文件路径 | 可选，如 `/pub/files/` |
| 使用显式 FTPS (TLS) | 勾选后新建任务默认启用 TLS |

保存后：新建 FTP 任务自动填充以上信息；主界面粘贴 `ftp://` 直链也会使用这组凭据。

### 3.2 Telegram 认证

| 字段 | 说明 |
|---|---|
| Bot Token | 形如 `123456:ABC-DEF...`；保存时自动校验有效性 |
| 默认 chat_id | 可选，仅作为新建任务的填写提示 |

保存后新建 Telegram 任务自动填充 Token，无需重复输入。

### 3.3 软件安全

- **启动密码**：
  - 启用/修改：填写"新启动密码 + 确认密码"（修改时还需"当前密码"），点击"启用 / 修改启动密码"，下次启动生效。
  - 清除：填写当前密码后点击"清除启动密码"。
  - 密码只保存 PBKDF2-SHA256 哈希（10 万次迭代 + 随机盐），无法还原明文；忘记密码需删除配置文件中的 `LockPasswordHash/LockPasswordSalt` 字段。
- **凭据存储安全**（自动生效）：FTP 密码与 Telegram Token 经 Windows DPAPI（当前用户）加密后落盘，密文以 `dpapi:v1:` 开头；其他用户或拷贝到其他电脑均无法解密。
- **立即清除已保存的 FTP 密码与 Telegram Token**：一键抹掉凭据。

## 4. 任务管理

| 操作 | 方式 |
|---|---|
| 暂停 | 任务卡片"暂停"按钮（下载中/解析中/做种中可用） |
| 继续 | 暂停/失败/停止的任务点"继续"；同一进程内复用连接，重启应用后自动续传 |
| 删除 | 任务卡片"删除" |
| 批量暂停 / 批量删除 | 底部状态栏按钮 |
| 查看失败原因 | 卡片"失败"行直接显示"错误码：具体原因" |

状态含义：等待中 / 解析中 / 下载中 / 已暂停 / 做种中 / 已完成 / 失败 / 已停止。

## 5. ffmpeg 配置

M3U8 合并与元信息探测使用 ffmpeg：

1. 设置路径：高级添加 → M3U8 Tab → "ffmpeg 路径"，填写 `ffmpeg.exe` 完整路径；
2. 或设置环境变量 `FFMPEG_PATH`；
3. 都未配置时自动在 PATH 中查找；找不到则 M3U8 使用内置 TS 拼接（功能可用，但转封装 mp4 能力受限）。

底部状态栏会实时显示检测结果，如"FFmpeg 可用 (M3U8 将使用内置拼接)"。

## 6. 状态与错误速查

| 现象 | 原因与处理 |
|---|---|
| BT 一直"正在获取元数据" | 磁力依赖公网 DHT；本机网络限制 UDP 时无结果。改用 .torrent 文件 |
| BT 种子/连接数一直为 0 | tracker 与 peer 端口（TCP/UDP 出站）被网络策略拦截；换网络或使用支持端口放行的环境 |
| `TG_HTTP_401` | Bot Token 无效，重新在设置中心填写 |
| `TG_FILE_TOO_LARGE` | 文件超过 Bot API 20 MB 上限 |
| `FTP_AUTH_FAILED` | 用户名或密码错误；检查设置中心凭据 |
| `HTTP_DNS_*` 类 | 域名解析失败；检查网络或链接拼写 |
| M3U8 提示密钥/分片错误 | 流加密方式不支持或分片 URL 过期（直播流时效性） |
| 完成后校验失败提示 | 下载字节与哈希不符，任务会标注具体分片/文件校验结果，可删除后重下 |

## 7. 数据存放在哪里

默认 `%APPDATA%\BitTomrrorApp`：`settings.json`（设置与加密凭据）、`tasks.json`（任务列表，重启自动恢复）、`torrents/`（种子与元数据）与各任务临时续传文件。可通过环境变量 `BITTOMRROR_APP_DATA` 自定义位置（便携使用）。

## 8. 常见问题

**Q：暂停后继续会重新下载吗？**
不会。HTTP/Telegram/FTP 从已下载字节续传（.part + Range/REST），BT 使用 MonoTorrent fast-resume，仅校验增量分片。

**Q：进度条会虚标吗？**
不会。进度、速度、peers 数均来自真实传输；"已完成"必须通过分片或文件哈希校验。

**Q：换电脑后凭据还在吗？**
settings.json 中的 DPAPI 密文无法在其他机器/用户解密，程序会将其视为空凭据——请在新机器重新配置。

**Q：忘记启动密码怎么办？**
关闭程序，编辑 settings.json 清空 `LockPasswordHash` 与 `LockPasswordSalt` 两个字段后重新启动。

**Q：Telegram 能下载大于 20 MB 的文件吗？**
当前版本不能（Bot API 限制）。程序会明确拒绝并提示，不会下载到一半失败。
