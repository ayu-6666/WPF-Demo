# MediaStudioVideo 功能使用说明

适用程序：`MediaStudioWpf48.exe`（模块 MediaStudioVideo）
适用对象：最终用户

---

## 1. 启动前准备

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / Windows 11（64 位） |
| 运行时 | .NET Framework 4.8（Windows 10 1903+ / Windows 11 通常已内置） |
| FFmpeg | `ffmpeg.exe` 需与 `MediaStudioWpf48.exe` 同目录，或通过环境变量 `FFMPEG_PATH` 指定 |
| 首次启动 | 建议从发布包解压后直接双击 `MediaStudioWpf48.exe`，不要单独拷贝 exe |

启动后左侧工具箱底部会显示 `FFmpeg 已就绪`（绿色圆点）。若显示 `未找到 FFmpeg`（红色圆点），请参考 [02-开发与环境部署](02-开发与环境部署.md#6-ffmpeg-部署) 配置 `FFMPEG_PATH`。

## 3. 按钮与控件状态含义

### 3.1 按钮五态

| 状态 | 视觉表现 | 说明 |
| --- | --- | --- |
| Normal | 主按钮蓝底白字；次按钮浅蓝底蓝字 | 可点击 |
| MouseOver | 叠加约 15% 的悬浮色，并出现轻微阴影，过渡 150 ms | 鼠标移入，不突兀跳变 |
| Pressed | 叠加更深压暗层，文字下沉 1 px | 鼠标按下反馈 |
| Disabled | 背景变灰、文字变浅灰、整体透明度约 0.6、光标恢复箭头 | 不可点击；例如路径未填好时的“开始处理” |
| Focused | 外圈 2 px 蓝色焦点环 | 键盘 Tab 或点击后获得焦点 |

按钮分三档：**主操作**（开始处理，蓝色）、**次操作**（选择输入 / 输出，浅蓝）、**危险操作**（关闭窗口，红色图标）。

### 3.2 “开始处理”何时可用

同时满足以下条件才可点击：

1. 未在处理中；
2. 已填写输入路径；
3. 已填写输出路径；
4. 当前工具为“添加背景音乐”时，还必须填写背景音乐路径。

不满足时按钮为禁用态，底部操作栏会给出具体提示（如“请先选择输入文件或目录”）。

### 3.3 列表

| 交互 | 表现 |
| --- | --- |
| 鼠标悬浮 | 行底色变为浅蓝灰，与选中行不同 |
| 选中 | 行底色加深，左侧出现 3 px 蓝色竖条 |
| 隔行底色 | 偶数行有极浅底色，便于横向阅读 |
| 键盘 | 支持方向键切换工具、Tab 进入列表 |

### 3.4 输入框、下拉框与勾选控件

- 输入框：无内容时显示灰色占位提示；聚焦时边框变蓝并出现焦点环；处理中整组路径输入框禁用。
- 下拉框：仅在“旋转 / 水平翻转”工具显示，提供 `hflip`、`vflip`、`transpose=1`、`transpose=2` 四个预设。
- 复选框：`完成后打开输出目录`，选中后勾选框变为蓝色对勾。
- 单选框：`日志：完整 / 摘要`，控制是否把 FFmpeg 每一行输出都写入日志。
- 进度条：任务开始前为 0%，成功后为 100%；**不解析 FFmpeg 实时进度**（见第 8 节）。
- 状态标签：`就绪` / `处理中` / `完成` / `失败`。

## 4. 通用操作流程

1. 在左侧工具箱点选一个工具；
2. 在“输入文件 / 目录”填写或点击 `选择输入`；
3. 需要时填写背景音乐；
4. 在“输出文件”填写或点击 `选择输出`；
5. 按需填写参数；
6. 点击右下角 `开始处理`；
7. 观察状态标签、进度条与日志；
8. 成功后如勾选 `完成后打开输出目录`，会自动在资源管理器中定位产物。

> 路径既可以用文件对话框选择，也可以直接粘贴完整路径。含空格或中文的路径无需手动加引号，程序会自动加引号。

## 5. 功能清单（逐工具）

| 工具 | 做什么 | 怎么用 | 会得到什么 | 参数 | 默认输出扩展名 |
| --- | --- | --- | --- | --- | --- |
| 音乐提取 | 从视频中导出音轨 | 选视频 → 选输出 → 开始 | MP3 音频文件 | 无 | `.mp3` |
| 添加背景音乐 | 给视频混入背景音乐并循环铺满 | 选视频 → 选音乐 → 选输出 → 开始 | 带背景音乐的视频（视频流不重编码） | 无（音量固定 0.25） | `.mp4` |
| 视频拼接 | 按文件名顺序拼接同规格视频 | 选择视频文件夹 → 选输出 → 开始 | 一个合并后的视频 | 无（只读取 `.mp4/.mov/.mkv`） | `.mp4` |
| 视频剪辑 | 截取指定时间段 | 选视频 → 填开始时间与时长 → 选输出 → 开始 | 重编码后的片段 | `剪辑开始时间`、`剪辑时长（秒）` | `.mp4` |
| M3U8 转 MP4 | 下载 HLS 流并封装为 MP4 | 粘贴 m3u8 网络地址或选择本地 m3u8 → 选输出 → 开始 | MP4 文件 | 无 | `.mp4` |
| 文件夹图片合成视频 | 把文件夹内 JPG 序列做成视频 | 选择图片文件夹 → 填帧率 → 选输出 → 开始 | 一段无声视频 | `帧率 / 图片帧率` | `.mp4` |
| 视频去码 / 去水印 | 用 `delogo` 修补矩形区域 | 选视频 → 填区域 → 选输出 → 开始 | 区域模糊修补后的视频 | `X`、`Y`、`宽`、`高` | `.mp4` |
| 视频画质增强 | 降噪 + 2 倍 Lanczos 放大 + 锐化 | 选视频 → 选输出 → 开始 | 分辨率翻倍、更锐利的视频 | 无 | `.mp4` |
| 视频提取 GIF | 按帧率生成调色板 GIF | 选视频 → 填帧率 → 选输出 → 开始 | 宽 480 px 的循环 GIF | `帧率 / 图片帧率` | `.gif` |
| 旋转 / 水平翻转 | 旋转或镜像画面 | 选视频 → 选择方式 → 选输出 → 开始 | 旋转 / 镜像后的视频（音频直通） | `旋转 / 镜像方式` | `.mp4` |
| 图片去码 / 去水印 | 图片局部修补 | 选图片 → 填区域 → 选输出 → 开始 | 修补后的图片 | `X`、`Y`、`宽`、`高` | `.png` |
| 图片高清增强 | 2 倍 Lanczos 放大 + 锐化 | 选图片 → 选输出 → 开始 | 放大后的图片 | 无 | `.png` |

> 默认扩展名只是文件对话框的初始值，最终格式由你确认的扩展名决定（例如把 `.png` 改成 `.jpg` 就会输出 JPEG）。

### 5.1 重点功能补充说明

**添加背景音乐**

- 背景音乐会被循环并截断到视频长度（`-stream_loop -1` + `-shortest`）；
- 视频流直接拷贝，不重新编码，速度快但要求容器兼容；
- 背景音乐音量固定为 0.25，未提供界面调节。

**视频拼接**

- 按完整文件名的字符串顺序（升序）拼接，不是自然排序；
- 只读取所选文件夹第一层的 `.mp4`、`.mov`、`.mkv`；
- 所有文件必须编码参数一致，否则可能拼接失败或出现音画异常；
- 中间生成的 concat 列表文件会在任务结束后自动删除。

**文件夹图片合成视频**

- 只识别文件夹内的 `.jpg` 文件（不区分大小写由 FFmpeg glob 决定）；
- 图片按 glob 顺序读取，建议事先统一尺寸并按 `001.jpg`、`002.jpg` 命名；
- 输出为无音轨视频。

**去码 / 去水印**

- 使用 FFmpeg `delogo` 滤镜对矩形区域做模糊修补，属于“遮盖式修补”，**不能还原被遮挡的真实内容**；
- `区域宽度/高度` 必须是正整数，且矩形必须在画面范围内；
- 区域坐标以左上角为 `(0,0)`。

## 6. 常见任务操作步骤

### 6.1 从视频提取 MP3

1. 左侧选择 `音乐提取`；
2. 点击 `选择输入`，选择视频；
3. 点击 `选择输出`，文件名以 `.mp3` 结尾；
4. 点击 `开始处理`；
5. 等待状态变为 `完成`，日志出现 `任务完成：...`。

### 6.2 给视频换背景音乐

1. 选择 `添加背景音乐`；
2. 选择视频与音乐；
3. 选择输出 `.mp4`；
4. 开始处理。若视频流不是 H.264/AAC，建议先转码再混音。

### 6.3 批量图片转视频

1. 把图片统一放进一个文件夹，仅保留 `.jpg`；
2. 选择 `文件夹图片合成视频`；
3. 点击 `选择输入`（此工具会弹出文件夹选择框）；
4. 帧率填 `25` 或 `30`；
5. 选择输出 `.mp4` 后开始。

### 6.4 截取视频片段

1. 选择 `视频剪辑`；
2. 开始时间填 `00:00:05`（时:分:秒）或 `5`（秒）；
3. 时长填秒数，例如 `10`；
4. 选择输出并开始。

## 7. 支持格式与输出位置

### 7.1 输入格式

| 选择方式 | 文件对话框过滤 |
| --- | --- |
| 文件（大多数工具） | `*.mp4;*.mov;*.mkv;*.ts;*.m3u8;*.png;*.jpg;*.mp3;*.wav`，也可切换“所有文件” |
| 文件夹（视频拼接、图片合成） | 文件夹选择框 |
| 背景音乐 | `*.mp3;*.wav;*.aac;*.m4a` |

实际解码能力取决于随包的 FFmpeg（当前包为 `ffmpeg version 2026-11-02-git-b034eb5e7e-essentials_build`，含 libx264、libx265、libmp3lame 等）。

### 7.2 输出位置

- **没有默认输出目录**，必须通过 `选择输出` 指定，或在输入框粘贴完整路径；
- 文件对话框会按工具预填扩展名（见第 5 节），不会自动创建目录；
- 输出文件已存在时，保存对话框会提示覆盖，FFmpeg 也会以 `-y` 直接覆盖；
- 勾选 `完成后打开输出目录` 后，成功后会自动打开资源管理器并选中产物。

## 8. 已知限制

| 限制 | 说明 |
| --- | --- |
| 无实时进度 | 进度条只表示 0%（开始）→100%（成功），不解析 FFmpeg 的 `time=` 输出 |
| 无取消 / 队列 | 一次只跑一个任务；处理中无法中断；任务处理中路径与浏览按钮被禁用 |
| 图片序列仅 JPG | 文件夹合成只匹配 `*.jpg`，PNG 序列需先转换 |
| 拼接要求规格一致 | 编码、分辨率、帧率不一致时可能失败 |
| 去码非还原 | `delogo` 只是区域修补，无法恢复被遮挡像素 |
| 语言 / 主题不持久化 | 切换只对当前进程生效，重启恢复“跟随系统语言 + 浅色主题” |
| 摘要日志 | 选择“摘要”后只记录开始 / 完成与错误，不记录 FFmpeg 逐行输出 |
| 音乐音量固定 | 背景音乐音量固定 0.25，界面不可调 |
| M3U8 依赖网络 | 远程流需要可访问的网络与正确的协议（允许 file/http/https/tcp/tls/crypto） |
| 锁屏环境限制 | 锁屏状态下文件夹选择框可能无法弹出，需解锁后使用 |
