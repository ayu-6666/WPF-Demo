### 5.2 其它用法

```powershell
# 只编 Debug 并打包
.\Build-Package.ps1 -Configuration Debug

# Debug + Release 都打包
.\Build-Package.ps1 -Configuration Both

# 只生成目录、不压缩（调试发布目录用）
.\Build-Package.ps1 -Configuration Release -NoZip

# 指定 FFmpeg
.\Build-Package.ps1 -Configuration Release -FfmpegPath "D:\Tools\ffmpeg\bin"

# 清空 artifacts 后重打（会删除历史 zip）
.\Build-Package.ps1 -Configuration Release -Clean
```

也可直接双击 `Build-Debug.cmd`、`Build-Release.cmd`、`Build-All.cmd`。

### 5.3 脚本行为

1. 定位 MSBuild：`-MSBuildPath` → `$env:MSBUILD_EXE` → `vswhere` → `PATH` → 常见安装目录；
2. `Rebuild` 指定配置；
3. 校验 `bin\<Configuration>\MediaStudioWpf48.exe` 存在；
4. 把整个输出目录复制到 `artifacts\MediaStudioWpf48_<Configuration>\`（暂存）；
5. 查找 `ffmpeg.exe`（参数 → `FFMPEG_PATH` → 项目根 → 输出目录 → `PATH`），并复制同目录的 `ffprobe.exe`、`ffplay.exe`；
6. 生成 `运行说明.txt`；
7. 压缩为带时间戳的 ZIP；
8. **删除暂存目录，只保留 ZIP**。

> `-NoZip` 时不压缩，也会保留暂存目录，便于直接运行验证；验证后请手动删除。

- 发布包中不需要 `bin`、`obj`、`.sln`、`.csproj`、`docs`。

## 8. 临时文件与中间产物约定

| 类型 | 位置 | 处理 |
| --- | --- | --- |
| 编译中间产物 | `bin\<Configuration>\`、`obj\` | 保留用于调试；发布时不复制 |
| 打包暂存目录 | `artifacts\MediaStudioWpf48_<Configuration>\` | 压缩成功后由脚本自动删除 |
| 发布包 | `artifacts\MediaStudioWpf48_<Configuration>_<时间戳>.zip` | 唯一需保留的产物 |
| 历史发布包 | `artifacts\*.zip` | 按需保留；`-Clean` 可清空 |
| 运行诊断日志 | exe 同目录 `startup-error.log` | 排查后可删除，不应进入发布包 |
| 验证截图 | 模块根目录 `verify_ui_*.png` | 文档证据，不进入发布包 |
| 临时解压目录 | `%TEMP%\mediastudio_pkgcheck` | 验证后删除 |

每次打包后请确认 `artifacts` 下没有 `MediaStudioWpf48_Debug` / `MediaStudioWpf48_Release` 文件夹残留。

## 10. 常见故障排查

| 故障 | 可能原因 | 排查 / 解决 |
| --- | --- | --- |
| `Build-Package.ps1` 找不到 MSBuild | VS 自定义安装路径未被 `vswhere` 收录 | 加 `-MSBuildPath "…\MSBuild.exe"`，或设置 `$env:MSBUILD_EXE` |
| `error MSB3644: 未找到 .NET Framework 4.8 的引用程序集` | 未安装 Developer Pack | 安装 .NET Framework 4.8 Developer Pack |
| `CS1617` / `LangVersion 7.3` 不支持 | 调用了 `v4.0.30319` 目录的旧 MSBuild | 使用 `MSBuild\Current\Bin\MSBuild.exe` |
| XAML 编译报 `InitializeComponent` 不存在 | 工程里设置了 `IntermediateOutputPath` 到临时目录 | 移除该属性，恢复默认 `obj\` |
| 打包后启动报缺少 DLL | 只拷了 exe；或直接在 ZIP 内双击运行 | 解压完整目录后运行；本工程无第三方 DLL |
| 启动提示找不到 FFmpeg | 未解压 `ffmpeg.exe` 或 `FFMPEG_PATH` 无效 | 确认 `ffmpeg.exe` 与 exe 同目录；`ffmpeg -version` 可执行 |
| FFmpeg 退出码非 0 | 参数、编码容器不兼容、路径含特殊字符 | 查看“完整日志”中的 stderr；确认输出扩展名与编码匹配 |
| 输出 0 字节 / 覆盖失败 | 输出文件被占用、目录不存在、无写权限 | 关闭占用程序；换可写目录后重试 |
| ZIP 超过 100 MB，邮件/IM 无法发送 | FFmpeg 二进制体积大 | 使用网盘；或剔除 `ffplay.exe`、`ffprobe.exe` 后重打 |
| 首次运行被 SmartScreen 拦截 | 未签名 exe | 右键属性“解除锁定”，或代码签名 |
| 打包脚本中文乱码 | `.ps1` 被另存为无 BOM UTF-8 | 用“UTF-8 with BOM”保存后重试 |
