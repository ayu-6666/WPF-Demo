# MediaStudioVideo 开发与环境部署

适用模块：`MediaStudioVideo`（工程名 `MediaStudioWpf48`）
面向对象：开发、构建、部署人员

---

## 1. 技术栈与实际版本

| 项目 | 实际值 | 说明 |
| --- | --- | --- |
| 语言 | C# 7.3 | 项目文件 `<LangVersion>7.3</LangVersion>` |
| 框架 | .NET Framework 4.8 | `<TargetFrameworkVersion>v4.8</TargetFrameworkVersion>` |
| UI | WPF（Windows Presentation Foundation） | 无第三方 UI 框架，未引入 MaterialDesign |
| 架构 | MVVM | `MainViewModel` + `RelayCommand` + `ToolItem` |
| 多媒体 | FFmpeg 外部进程 | 随包为 `ffmpeg version 2026-11-02-git-b034eb5e7e-essentials_build` |
| 包管理 | 无 NuGet 依赖 | 只引用 .NET Framework 自带程序集 |
| 构建 | MSBuild（VS 安装） | 本机实测 MSBuild 18.10.1（VS 18 Professional 自定义安装路径） |
| 脚本 | PowerShell 5.1 | `Build-Package.ps1`，`.cmd` 为双击包装 |

> 本项目不是 .NET 6+ / WPF Core 工程，**不要使用 `dotnet build` / `dotnet publish`**，请使用 MSBuild。

## 5. 编译与调试

### 5.1 Visual Studio

1. 打开 `MediaStudioWpf48.sln`；
2. 选择 `Debug | Any CPU`；
3. F5 启动；
4. 将 `ffmpeg.exe` 放到 `bin\Debug\`，或设置环境变量 `FFMPEG_PATH` 后重启 VS。

### 5.2 命令行（实测通过）

```powershell
& "C:\Tang\IDE\Microsoft Visual Studio\18\Professional\MSBuild\Current\Bin\MSBuild.exe" `
  "d:\tang\vs-workspace\WPF-Demo\MediaStudioVideo\MediaStudioWpf48.sln" `
  /m /t:Build /p:Configuration=Debug "/p:Platform=Any CPU" /v:minimal
```

实测输出：`MediaStudioWpf48 -> d:\tang\vs-workspace\WPF-Demo\MediaStudioVideo\bin\Debug\MediaStudioWpf48.exe`，退出码 0。

### 5.3 启动失败诊断

- 启动或运行时异常会写入 exe 同目录的 `startup-error.log`（UTF-8，追加写）；
- 界面初始化失败会弹出 `Media Studio - Startup Error` 对话框；
- 排查时先看 `startup-error.log`，再检查 `FFMPEG_PATH`。

### 5.4 代码组织约定

| 位置 | 职责 | 修改建议 |
| --- | --- | --- |
| `App.xaml` | 全部颜色、圆角、字号、间距与控件模板 | 换肤优先改这里 + `ThemeManager` |
| `Services/ThemeManager.cs` | 浅色/深色画刷赋值 | 新增画刷键时必须同步两套主题 |
| `Services/LocalizationManager.cs` | 中英文词典与 `Loc` 标记扩展 | 新增文案必须同时补 `zh-CN` 与 `en-US` |

| `Services/FfmpegService.cs` | 查找 ffmpeg、异步执行、日志回调 | 不要在主线程同步等待进程 |

## 6. FFmpeg 部署

解析优先级（`FfmpegService.ResolveFfmpegPath()`）：

1. 环境变量 `FFMPEG_PATH`（进程 → 用户 → 机器），支持目录或 `ffmpeg.exe` 完整路径；
2. 程序目录下的 `ffmpeg.exe`；
3. 系统 `PATH` 中的 `ffmpeg.exe`。

设置用户环境变量：

```powershell
[Environment]::SetEnvironmentVariable('FFMPEG_PATH', 'D:\Tools\ffmpeg\bin', 'User')
# 或指向文件
[Environment]::SetEnvironmentVariable('FFMPEG_PATH', 'D:\Tools\ffmpeg\bin\ffmpeg.exe', 'User')
```

检查：

```powershell
$env:FFMPEG_PATH
ffmpeg -version
```

> 修改环境变量后必须完全退出并重新启动程序（以及 VS / 终端），新进程才会读取到。
> 打包时把 `ffmpeg.exe` 放进 `bin\<Configuration>\` 或通过 `-FfmpegPath` 指定，脚本会一并复制 `ffprobe.exe`、`ffplay.exe`（若同目录存在）。

## 8. 常见环境问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `CS1617: ... LangVersion 7.3` | 使用了 `C:\Windows\Microsoft.NET\Framework\v4.0.30319\MSBuild.exe` 旧版 | 改用 VS 自带 MSBuild（如 `MSBuild\Current\Bin\MSBuild.exe`） |
| `Build-Package.ps1` 提示找不到 MSBuild | VS 安装在非标准目录，`vswhere` 未收录 | 加 `-MSBuildPath <path>`，或设置 `$env:MSBUILD_EXE` |
| 启动即报 `找不到 FFmpeg` | 未放 `ffmpeg.exe`，或 `FFMPEG_PATH` 未生效 | 放到 exe 同目录，或重新设置环境变量后重启 |
| 生成 XAML 代码丢失、`InitializeComponent` 找不到 | 在工程文件里硬编码 `IntermediateOutputPath` 到临时目录 | 删除该配置，使用默认 `obj\` |
| 界面文字乱码 / 脚本语法错误 | PowerShell 5 将无 BOM 的 UTF-8 `.ps1` 按 ANSI 解析 | 脚本保存为“带 BOM 的 UTF-8” |
| 锁屏时点“选择输入”无反应 | `FolderBrowserDialog` / 文件对话框需要活动桌面 | 解锁桌面后重试 |
| 高 DPI 下界面模糊 | 进程未声明 DPI 感知 | WPF 默认按系统 DPI 缩放；如需逐显示器感知，需在 app.manifest 中声明 |
| 运行时报 `startup-error.log` 写入失败 | exe 所在目录无写权限（如 Program Files） | 解压到可写目录，或给目录写权限 |

## 9. 界面样式扩展约定

新增控件时优先复用 [App.xaml](../App.xaml) 中的资源，不要在页面里硬编码颜色 / 圆角：

| 资源键 | 用途 |
| --- | --- |
| `Accent` / `SecondaryBg` / `Danger` | 主 / 次 / 危险色 |
| `WindowBg` / `PanelBg` / `LineColor` | 背景与分隔线 |
| `TextPrimary` / `TextSecondary` / `TextTertiary` | 三级文字 |
| `RadiusSm` / `RadiusMd` / `RadiusLg` | 6 / 8 / 14 圆角 |
| `FontXs` ~ `FontXl` | 11 / 12 / 13 / 15 / 26 字号 |
| `PrimaryButton` / `SecondaryButton` / `DangerButton` / `GhostButton` | 按钮样式 |
| `CardBorder` / `CardTitle` / `FieldLabel` / `HintText` | 卡片与文本样式 |

新增主题色时：

1. 在 `App.xaml` 增加 `SolidColorBrush`；
2. 在 `ThemeManager.Apply` 的浅色 / 深色两套值中同步 `Set(...)`；
3. 页面用 `{DynamicResource Key}` 引用，才能即时换肤。
